Penyimpanan Langsung ke Google Sheets
Setiap suara siswa otomatis tercatat ke Google Spreadsheet Anda secara realtime.
File script Google Apps Script siap pakai sudah tersedia di folder: google-sheet-voting-script.gs.
Cara Menghubungkan Google Sheet dalam 1 Menit:
  1. Buka Google Sheets di browser Anda, buat spreadsheet baru beri judul "Hasil Voting Nevastra 2026".
  2. Klik menu Ekstensi (Extensions) > Apps Script.
  3. Buka file google-sheet-voting-script.gs di folder web ini, salin seluruh kodenya dan tempel ke Apps Script editor.
  4. Klik tombol biru Deploy (Terapkan) > New deployment (Deployment baru) > Pilih Web app.
  5. Atur Execute as: Me dan Who has access: Anyone (PENTING agar siswa bisa kirim suara).
  6. Klik Deploy, izinkan akses akun (Review permissions -> Advanced -> Go to ... -> Allow), lalu salin Web app URL (berakhiran /exec).
  7. Tempelkan URL tersebut pada kolom input di atas, lalu klik Simpan URL Sheet. Selesai!
